HERRAMIENTA DE MANTENIMIENTO

Recuperar Datos Perdidos

Si los deportistas realizaron sus pruebas pero los datos no aparecen en el dashboard, usa esta herramienta para re-sincronizar las mediciones directamente desde la base de datos. Útil después de una falla del sistema o un despliegue fallido de Cloud Functions.

¿Cómo funciona?
El sistema buscará las mediciones almacenadas por la app móvil para la fecha indicada y las forzará a aparecer en el dashboard. Solo funciona si la app guardó los datos localmente.
